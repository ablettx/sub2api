## 参数与契约初值

下列为已确认并实现的初值，不是线上配置状态；超过上界或非法输入必须报错，不能静默转成无限额。

| 参数 | 初值或规则 | 依据与验证 |
| --- | --- | --- |
| 新周期或估值缺失的暂用期限 | 30 分钟；配置范围 10 分钟～24 小时；跨周期不自动续期 | 现有 `openAIProbeCacheTTL` 为 10 分钟；30 分钟作为初值，需覆盖到期前后及长期零利用率，不声称三次采样必然成功 |
| 请求占用租期与续期 | 租期 15 分钟，每 5 分钟续期，持续至实际结算完成 | 沿用现有占用租期量级；超时未知状态不能直接释放或当作免费 |
| 单次配额存储操作 | 2 秒超时；锁顺序固定；仅对可重试的数据库竞争最多重试 2 次 | 与现有预留操作超时一致；原子事务、超时回滚及无重复上游调用需验证 |
| 未指定输出长度的估计 | 复用现有最大输出估计，当前默认 8,192 Token | 仅用于在途占用估算，不改写请求输出限制，不声称是严格费用上界 |
| 校准调用 | 默认不自动触发付费校准；管理员必须明确用户、分组、正数费用预算、次数和输出边界 | 无有效样本时仍可待初始化，不能为了成功而自动扩大预算；实际结算尾差需显示并停止继续采样 |
| 校准请求保护 | 1～3 次请求、单次输出不超过 256 Token；不启用工具或媒体；总费用预算为必填项，无隐式付费默认值 | 小样本可能仍无法产生正利用率，必须允许明确失败并停止；输入上界和费用预留复用现有定价 |
| 回退目标 | 默认空列表，管理员显式配置有序分组，并与用户现有权限取交集 | 所有回退共用有界尝试预算与访问集合，不能每换分组重置重试次数 |
| 协议错误 | 已耗尽/占用不足为 429；待初始化、估值或依赖不可用为 503；无法迁移会话为 409 | 保留各协议 envelope；已升级 WebSocket 返回错误帧并沿用 1008 策略拒绝或 1013 暂时不可用关闭语义，不发明与现有协议冲突的封装 |

若运行证据表明初值必须调整，先记录原因并同步设计、计划及边界用例；不得以调大期限、清零用量或临时无限放行掩盖根因。

## 实际路由矩阵

路径以源码 `backend/internal/server/routes/gateway.go` 为基线；后续实现如发现新入口，先更新矩阵和验收，不默认跳过。这里的纳入只针对受控 OpenAI OAuth 账号，不给其他平台新增配额。

| 编号 | 路径与执行链 | 首版处理 |
| --- | --- | --- |
| R01 | `POST /v1/responses`、`/responses`、`/backend-api/codex/responses`，及受允许的 `/*subpath` | 统一准入与结算，包含旧 Compact 分支；明确排除不执行模型的 input-token 查询 |
| R02 | 上述三个前缀的 `GET /responses` WebSocket | 握手后的首次及后续 `response.create` 均检查，不能只看建连时额度 |
| R03 | `POST /v1/chat/completions`、`/chat/completions` | `openai_chat_completions.go` 及现有转换、原始转发分支统一接线 |
| R04 | `POST /v1/messages` 的 OpenAI 分发 | `OpenAIGateway.Messages` 及工具续链保持同一用户、账号与计费上下文 |
| R05 | `/v1` 与根路径的 `POST /images/generations`、`/images/edits` | 同步 Images 的普通与 multipart 入口全部准入和计费 |
| R06 | 上述图片路径的 `/async`，以及任务轮询 | 后台复用 `Images` 时重新准入，创建和轮询不能额外扣费或使用旧授权 |
| R07 | `POST /v1/alpha/search`、`/alpha/search`、`/backend-api/codex/alpha/search` | 独立搜索可选 OAuth，必须计入实际扣费并执行配额 |
| R08 | `POST /v1/live`、`/backend-api/codex/realtime/calls` 及其 sideband | 当前 Live 未计费，首版排除受控账号并说明原因；未受控账号原行为保留，不在本期新增收费 |
| R09 | `POST /v1/embeddings`、`/embeddings` | 现有能力仅允许 API Key；保留排除 OAuth 的反向测试，不新增 OAuth 支持 |
| R10 | `GET /models`、`/usage`，`POST /messages/count_tokens`、允许的 Responses input-token 查询及其既有别名 | 保留鉴权和能力检查，不为只读/计数操作另扣配额；证明不能借这些入口执行未计量生成 |
| R11 | Gemini/Antigravity/Grok/TypeSafe、批量图片和其他供应商专有入口 | 保留平台与能力边界；当前批量图片 provider 为 Gemini/Vertex，不接入受控 OAuth；测试防止类型误路由 |
